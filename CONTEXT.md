
# Context

## Language

**Issue tracker**:
The tool that hosts a repo's issues: Linear

**Issue**:
A single tracked unit of work inside an **Issue tracker**: a bug, task, spec, or slice produced by `to-issues`.

**WIKI**:
An obsidian wikipedia that hosts the work over projects, stored in the `v` vault.

Project:
Individual work stream that has it's own representative in Issue Tracker and WIKI.

**Source Note**:
Note in the WIKI that contains summarized information about a publication.

**Topic Note**:
Note in the WIKI that contains a brief description of topic and sources that reference it.

PRD:
Product requirement document - stored in the WIKI project, is a base to a set of Issue tracker issues.

## Relationships

- The project is established first in the WIKI
- The project is established in Issue Tracker
- An PRD is generated in the WIKI project
- PRD is transfered to issues in the Issue tracker
- An **Issue tracker** holds many **Issues**
- WIKI can store many projects, source notes and topic notes
