# Read-only query and linting

## Query

Resolve the project first, then search its `requirements.md`, `PRDs/`, `Meetings.md`, and any relevant source or topic notes. State which material supports each answer. Use the project Base as a navigation aid, not as a substitute for reading the underlying notes.

## Lint

Check only:

- required project files and frontmatter keys;
- internal links and PDF annotation links where present;
- append-only log format and whether it contains only requirements/PRD events;
- `.base` YAML syntax, referenced properties, and view scope;
- the presence of the raw Linear project URL in requirements when a Linear project has been resolved.

Report findings without changing notes. Offer a precise repair plan and wait for approval before making any repair.
