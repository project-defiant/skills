# Context

## Language

**WIKI**:
An obsidian wikipedia that hosts the work over projects, stored in the vault at `$SZYMON_WIKI`.

**Project**:
Individual work stream that has its own folder in the WIKI.

**Source Note**:
Note in the WIKI that contains summarized information about a publication.

**Topic Note**:
Note in the WIKI that contains a brief description of topic and sources that reference it.

**PRD**:
Product requirement document - stored in the WIKI project, is the base for implementation work.

## Relationships

- The project is established in the WIKI
- A PRD is generated in the WIKI project
- WIKI can store many projects, source notes and topic notes
